# Choose a set structure

Use ordinary and advanced methods for a clear reason.

## Straight sets and down sets {#training-methods-straight}

Straight sets repeat a movement with enough rest for the target muscle to be the limiting factor again. Before the next set, consider the target muscle, synergists, overall readiness and breathing. A fixed short rest is counterproductive if cardiorespiratory fatigue stops the set before the intended muscle is challenged. The authors make straight sets the foundation of most programs.

Down sets reduce load after earlier sets so later work stays within the chosen repetition range. They are not the same as short-rest drop sets. Keeping the same exercise saves additional warm-up time and preserves comparability; adding a new movement is useful only if its benefits justify the transition and its different demands.

## Advanced methods and their limitations {#training-methods-advanced}

| Method | Purpose and limitation |
| --- | --- |
| Giant sets | Reach a total-repetition target; weekly performance is harder to compare |
| Non-overlapping supersets | Pair unrelated or antagonist muscles to save time; systemic fatigue can still interfere |
| Pre-exhaust supersets | Isolation then a compound for the same target; changes the limiting factor and increases local fatigue |
| Myoreps | Short-rest mini-sets after an initial hard set; best when the target muscle, not breathing, limits work |
| Drop sets | Reduce load between short-rest sets; track the reductions rather than improvising endlessly |
| Blood-flow restriction | Can make light loads effective; requires appropriate equipment, screening and qualified guidance |

Advanced methods are tools, not guaranteed upgrades. Highly systemic exercises are often poor choices for very short rests. Novel methods still need progression, recoverability and a clear role.

## Track the details of the method {#training-methods-method-details}

In the source’s myorep example, an initial 10–20-repetition set at about 0–2 RIR is followed after a few breaths by smaller 5–10-repetition bouts. Drop sets add load reductions to a similar short-rest idea. They target efficiency and local fatigue; their suitability depends on the target, not on how much discomfort they produce. Pre-exhaust pairs use an isolation first so the same muscle can become limiting in the following compound.

The source’s Table 5.1 proposes accounting heuristics: a conventional straight or down set counts as one; a giant-set bout, drop set or occlusion set may be counted as about 2/3 of a straight set for the primary target; a myorep mini-set may similarly count as 2/3, sometimes one when fatigue response is high. A non-overlapping superset counts one set for each target, while the pre-exhaust pair is roughly two sets, or about 1.5 in the authors’ finer estimate. These fractions are author bookkeeping conventions, not verified biological conversion constants.

If you use such a convention, label it and keep the method, rest, load and range consistent. Do not combine an unlabelled fractional estimate with ordinary set counts and assume precise equivalence. Blood-flow-restriction setup is intentionally not taught as a self-application procedure here.

## Recap

- Rest long enough to challenge the intended muscle.
- Select advanced methods for a specific benefit and track their costs.
