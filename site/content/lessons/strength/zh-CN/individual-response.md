# 相同原则，不同剂量

个体化是在共同原则内调整剂量。

## 个体间与个体内差异 {#individual-response-1}

个体间差异指不同人对相同训练的不同反应；个体内差异指同一人的反应随时间改变。即使遗传条件不变，训练经验、睡眠、饮食与压力也会改变。因此两年前有效的计划是一条证据，而不是永久的个人标签。

来源把实用调整集中在五方面：MRV、疲劳与能力衰退、发展阶段与目标、动作选择，以及动作技术。这让个体化成为可管理的工作。它通常改变相关训练的数量与排列，而不是为每个人发明一套全新生理原则。

> Scientific Principles of Strength Training, pp. 308–317 (printed page labels; PDF page index is label minus 1).

## 能力与疲劳的下降速度不同 {#individual-response-2}

有的人疲劳下降快、能力保留久，也有人相反。这会影响减量幅度与训练间隔，但不能只凭体型推断。既往可比训练与比赛记录，可以帮助形成工作假设。

书中的初级、中级和高级标签，主要指发展状态与需求，年限只是粗略示例。初学者通常需要广泛发展技术与肌肉；中级者可强化高收益优势；高级者则可能更多投入限制因素、细致巅峰准备与较长疲劳管理。改变体重级别等目标，在任何阶段都可能改变这些优先级。

> Scientific Principles of Strength Training, pp. 308–317 (printed page labels; PDF page index is label minus 1).

## 使调整匹配证据 {#individual-decision-map}

| 证据或差异 | 候选变量 | 为解释结果需保持什么 |
|---|---|---|
| 可恢复剂量过低或过高 | 组数与单课量 | 动作与努力定义 |
| 进阶过急 | 起点与增幅 | 目标及比较动作 |
| 变式适配或迁移差 | 动作选择 | 足够稳定的其他负担情境 |
| 技术不符合身体比例 | 具体技术细节 | 任务标准与受控执行 |
| 能力与疲劳下降速度不同 | 减量时机与幅度 | 可比结果记录 |

平均可恢复量相同，不代表进阶方式相同。某人可能需要较低起点、较大增幅；另一人能承受较高起点，却需要较小增幅。来源建议通过反复阶段发现差异，而不是把最大增幅当作积极性的宣言。

偏好可以帮助在有效选项中选择；陌生感也可能让初期有用的技术显得别扭。应区分可耐受学习与不适合的动作，在足够练习后评价，而不只看第一次。个人计划因此是由记录支持、可以修订的模型，不应变成无法检验的主张，把每次不佳都解释为此人是例外。

> Scientific Principles of Strength Training, pp. 308–336 (printed page labels and 1-based PDF pages coincide; 0-based PDF index is label minus 1).

## 要点回顾

- 个体化是在共同原则内调整剂量。
- 同一个人的需求也会随时间改变。
