# 训练迁移的连续谱

专项性是连续谱，不等于外形模仿。

## 从肌肉到比赛动作 {#specificity-spectrum-1}

专项性指训练目标任务所依赖的系统。增加深蹲相关肌群的体积属于广义专项；提高其产力能力更狭窄；在接近比赛的负荷下完成合规深蹲，则更狭窄。辅助动作不必外观完全相同，但应能说明它如何迁移到目标。

原书的专项性树把肌肉发展连接到多个运动。共享基础能力不等于不同运动完全相同。若目标是最大化力量举总成绩，越接近比赛就越应强调真正的深蹲、卧推与硬拉；较早阶段则可以更多发展其基础能力。

> Scientific Principles of Strength Training, pp. 26–43 (printed page labels; PDF page index is label minus 1).

## 兼容性也是资源问题 {#specificity-spectrum-2}

本书讨论力量与耐力、柔韧性、功率、肌肥大以及专项力量之间的关系。不同训练既可能相互支持，也可能争夺时间、可恢复训练量，以及下一堂课所需的生理状态。作者最强烈的批评，针对的是把最大力量举成绩作为唯一目标时仍投入大量耐力训练；这不意味着所有心肺活动都有害。

力量强调高产力，功率则结合力与速度。举起时尽力加速，不代表接近极限的杠铃会快速运动。柔韧性应满足所需姿势，而额外练习需证明其时间和恢复成本值得。这些是目标相关的权衡，不是运动价值的普遍排名。

> Scientific Principles of Strength Training, pp. 26–43 (printed page labels; PDF page index is label minus 1).

## 迁移与干扰机制图 {#compatibility-map}

| 组合 | 可能支持 | 来源讨论的可能冲突 |
|---|---|---|
| 力量 + 耐力 | 足够一般适能帮助耐受训练 | 大量额外工作、疲劳及竞争性适应 |
| 力量 + 柔韧性 | 获得所需姿势 | 不必要幅度训练占时间，急性效应取决于剂量时机 |
| 力量 + 功率 | 共享高产力意图 | 过轻的速度重点可能缺少目标产力刺激 |
| 力量 + 肌肥大 | 更多肌肉支持后续产力 | 高量疲劳可能损害眼前大重量执行 |
| 一般 + 专项力量 | 一般能力支持比赛动作 | 极限表达需要更精确技能和更低疲劳 |

作者从肌肉结构、结缔组织受力方向与神经协调解释比赛专项性增加。肌内运动单位、肌群间贡献及完整动作的时序，都可能在不同变式间变化。实践结论是提前转向真实比赛技术、留出适应时间，而不是在最后几周最重训练时才发现差别。

例如，触胸即推的卧推表现不能证明暂停卧推能力。用前者安排后者，可能高估可完成次数。同样，硬拉取消助力带也改变约束。来源把外部训练的情境分为四维：训练量、冲击或扰动、方式和时机。少量独立爱好不同于重训练前的大量活动。一般身体准备（GPP）也应与运动相关：它准备后续专项训练所需能力，而不只是制造耗竭。

> Scientific Principles of Strength Training, pp. 29–57 (printed page labels and 1-based PDF pages coincide; 0-based PDF index is label minus 1).

## 要点回顾

- 专项性是连续谱，不等于外形模仿。
- 同时评估迁移价值与恢复成本。
