# 力竭、速度训练与负担暴增

根据完整训练序列评价超负荷。

## 刺激与代价并不相同 {#overload-errors-1}

作者质疑始终达不到足够力量或肌肥大刺激的速度训练。杠铃移动快，不代表对每个目标都产生了足够超负荷。辅助动作同样要对目标能力具有足够挑战；只为逃避努力而选容易动作，会削弱计划。应记录可比条件下反复出现的最好表现，而不是依靠记忆。

另一极端是每个大重量组都做到力竭，这可能带来不成比例的疲劳和不稳定执行。本书对力量举通常更倾向于接近而不达到力竭的高挑战训练。努力程度增加可能提升即时刺激，却降低以后能够重复完成的有效工作。

> Scientific Principles of Strength Training, pp. 86–103 (printed page labels; PDF page index is label minus 1).

## 保护下一次训练 {#overload-errors-2}

一次临时加码的挑战日，可能远超原定剂量，使下一周变成纯恢复而不是训练。首堂课确有刺激，但收益存在上限，干扰后续训练的成本却可能继续。应比较完整训练序列，而不只是看某一堂课多么惊人。

可问：增加是否经过计划？是否服务于当前目标？下一堂训练仍能完成其目的么？进阶是否依据实际反应？心理投入很重要，但疲劳或疼痛都不应被视为有效超负荷的证明。后续章节将解释计划恢复如何支持持续进阶。

> Scientific Principles of Strength Training, pp. 86–103 (printed page labels; PDF page index is label minus 1).

## 让进阶可以解释 {#overload-decision-map}

| 观察 | 先问什么 | 为什么重要 |
|---|---|---|
| 杠铃增重但组次下降 | 负荷训练量真的增加了吗？ | 刺激变化可能服务于另一阶段 |
| 极轻重量快速重复 | 目标产力或肌肉刺激足够吗？ | 最大意图不等于低负荷速度训练 |
| 更难的辅助动作 | 是否在可恢复剂量内挑战有用能力？ | 更大全身扰动本身不是目标 |
| 临时纪录训练 | 接下来计划课还能有效吗？ | 单课收益可能损失后续机会 |
| 声称新的最好成绩 | 幅度、器械与努力是否可比？ | 条件不一致可能伪装成进阶 |

本书为其力量举目标偏好充分的复合自由重量辅助训练，并提出杠铃、哑铃、绳索到器械的顺序。这是基于预期总体扰动的作者偏好，不是已经普遍证实的肌肥大效果排名。来源本身也允许在全身恢复受限、却需要额外局部训练时使用较低扰动的孤立动作。**目标刺激应与全身代价分开评价。**

最大意图指努力施力，不要求观察到的杠铃速度快。来源认为速度日的表面收益，可能来自低要求与恢复作用，而非速度练习本身。推断特殊机制前，先确定这堂课的角色。记录实际重量、组次和执行方式，可以避免把记忆中的“最好”变成虚构进阶基准。

> Scientific Principles of Strength Training, pp. 78–103 (printed page labels and 1-based PDF pages coincide; 0-based PDF index is label minus 1).

## 要点回顾

- 根据完整训练序列评价超负荷。
- 努力要有目的，也要有可恢复的剂量。
