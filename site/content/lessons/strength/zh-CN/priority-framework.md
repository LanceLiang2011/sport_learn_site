# 训练决策框架

先解决基础问题，再精细调整。

## 七项原则 {#priority-framework-1}

作者的排序为：**专项性 → 超负荷 → 疲劳管理 → 刺激—恢复—适应 → 变化 → 阶段促进 → 个体差异**。这是训练决策框架，不是各原则贡献百分比的实测结果。专项性决定什么适应值得追求；超负荷提供有效刺激；疲劳管理让有效训练能够反复进行；后面几项则进一步优化训练时机、形式与个体匹配。

不同动作、频率或进阶规则的计划，都可能遵循相同原则。本书提供的是推理方法，而不是一个专有固定方案。

> Scientific Principles of Strength Training, pp. 8–11, 21–25 (printed page labels; PDF page index is label minus 1).

## 按顺序检查 {#priority-framework-2}

假设一个卧推计划每周都精心更换动作，却没有足够的推举训练，也没有进阶。改进轮换方式不能弥补相关刺激缺失。应先问计划是否训练了目标所需肌群与技能，再问刺激是否足够并随时间发展，随后判断训练负担能否恢复。

这些问题得到回答后，才应把重点放在频率、变化与阶段细节上。这个顺序避免小调整掩盖大问题。原则也互相约束：若增加超负荷破坏了恢复，就不是越多越好；全年保持最高专项性，也可能妨碍肌肉和一般力量的发展。

> Scientific Principles of Strength Training, pp. 8–11, 21–25 (printed page labels; PDF page index is label minus 1).

## 为什么顺序重要 {#principle-decision-map}

| 优先级 | 核心问题 | 后一原则不能修复什么 |
|---|---|---|
| 专项性 | 是否训练所需系统？ | 跑步即使持续进阶，也不会自动变成专项深蹲 |
| 超负荷 | 是否有足够且渐进的刺激？ | 休息不能创造缺失的刺激 |
| 疲劳管理 | 高要求工作能否持续有效？ | 理想频率不能挽救无限过量要求 |
| SRA | 刺激大小和间隔是否合理？ | 动作新奇不能修复所有日程问题 |
| 变化 | 刺激是否仍有效且目标明确？ | 阶段名称不保证变式相关 |
| 阶段促进 | 前期工作是否支持后期？ | 个体化不能逆转缺失的准备阶段 |
| 个体差异 | 剂量和细节怎样匹配此人？ | 称作个人计划不代表免于其他原则 |

前三项构成作者的核心可行框架：专项性给方向，超负荷提供适应机会，疲劳管理使过程能够重复。SRA 排序较后，是因为基础到位时，多种合理日程都可能有效。变化能优化已有进步的计划，但改变仍要专项且足够有挑战。阶段促进能改善长期组织，却不是每个初学者短期进步的必要条件。个体差异很重要，但多数调整是在共同机制内修改，而非替换机制。

**应用：** 假设某运动员动作轮换精巧，却相关工作过少，应先检查剂量。若剂量相关且充足，但表现反复崩溃，则检查可恢复性。两者都合理后，再研究课间分布和长期刺激停滞。这是有顺序的调查，并不声称每次平台期都只有单一原因。

> Scientific Principles of Strength Training, pp. 21–25, 42–43, 74–75, 121–122, 207–208, 255, 286–288, 316–318 (printed page labels and 1-based PDF pages coincide; 0-based PDF index is label minus 1).

## 要点回顾

- 先解决基础问题，再精细调整。
- 层级用于权衡，不代表精确贡献百分比。
