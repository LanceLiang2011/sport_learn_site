# 为什么可恢复剂量会变化

工作能力与恢复共同约束 MRV。

## 工作能力与恢复相遇 {#mrv-context-1}

工作能力指能够完成多少训练，恢复能力指之后恢复准备状态并产生适应的能力。MRV 同时受到两者约束。针对任务的训练适能提高，可能扩展工作能力，但睡眠不足或饮食限制仍会降低可恢复剂量。某阶段能承受的剂量，不能不加调整地搬到另一负荷区间。

即使组数、次数和重量相同，接近力竭程度仍很重要。反复把每组做至力竭，可能降低可持续训练量。应同时记录实际次数、努力程度和负荷，并在生活或训练条件改变时更新 MRV 估计。

> Scientific Principles of Strength Training, pp. 121–142 (printed page labels; PDF page index is label minus 1).

## 动作与人为什么不同 {#mrv-context-2}

作者讨论了动作类别、运动幅度、肌肉量、绝对力量、经验、肌纤维特点、性别相关均值和技术。总体上，他们认为硬拉比深蹲更易累积疲劳，卧推较少，但也承认个体不同。这些是趋势，不是不同动作之间的固定换算系数。

即使 1RM 百分比相同，更强壮或体型更大的人也可能造成更大的绝对扰动。更高效的技术可减少不必要负担。群体平均值不能决定某个人的精确恢复日程，单次重复测试也不能可靠读出肌纤维类型。实用结论是为每项主要动作分别记录反应。

> Scientific Principles of Strength Training, pp. 121–142 (printed page labels; PDF page index is label minus 1).

## 阶段特定上限与恢复工具 {#fatigue-decision-map}

| 情境 | 来源希望保留什么 | 观察什么 |
|---|---|---|
| 肌肥大 | 持续肌肉发展 | 反复工作能力与恢复情境；肌肉量难以急性测量 |
| 力量 | 大重量产力表现 | 可比次数表现与执行 |
| 巅峰期 | 稳定极限负荷表达 | 专项重复成功与技术 |
| 积极休息 | 快速疲劳降低 | 低要求是否确实允许恢复 |

本书在有用时间尺度，尤其是中周期上定义 MRV，而非根据某一差组判断。其图示从低于平均上限开始，逐步接近，可能在计划减量前短暂超过。这不意味着每个早期周都应已达到最大，也不意味着可以根据一堂没精神的课测出肌肉流失：许多场地指标只是间接且非特异的近似信号。

休息日还有心理作用。通勤、准备及健身房与困难工作的关联，本身也可能成为要求；轻课不能替代离开一天的全部收益。积极休息可以有方向地用于技术学习、柔韧限制和适当管理的康复，而不变成新的超负荷阶段。来源一处说约两周，另一处说 2–4 周，汇总表又说 1–3 周。这些变化强调共同原则与个体反应，而不是虚假的日历精度。

> Scientific Principles of Strength Training, pp. 120–160, 179–182, 343 (printed page labels and 1-based PDF pages coincide; 0-based PDF index is label minus 1).

## 要点回顾

- 工作能力与恢复共同约束 MRV。
- 相同百分比不保证相同疲劳。
