# 建立、强化、表达

顺序有效的前提是先前适应得到保留。

## 为什么顺序有用 {#phase-sequence-1}

[阶段促进](term:phase-potentiation)通过组织训练，使先前适应支持后续适应。作者对力量举的核心顺序是：发展肌肉 → 基础力量 → 巅峰表现。更多肌肉为后续产力提供基础，一般力量则为专项极限表现提供能力。巅峰期放在最后，因为它准备比赛日所需的表达方式。

该论证结合专项性、定向适应、兼容性与顺序，但并不声称其他方法无效。作者把阶段促进排在专项性、超负荷和疲劳管理之后，并认为其额外收益相对有限。精致的阶段图不能挽救缺少足够相关刺激的训练。

> Scientific Principles of Strength Training, pp. 278–291 (printed page labels; PDF page index is label minus 1).

## 适应衰退形成约束 {#phase-sequence-2}

只有有用适应能保留，前一阶段才能促进下一阶段。维持通常比发展所需刺激更少，但不是完全不需要。低训练量巅峰期过长，可能使肌肉或一般力量下降；反之，尚未形成有意义适应就换阶段，也可能无法建立稳定基础。

来源给出的可能时长很宽：肌肥大或力量阶段约三周至六个月，巅峰期约三周至三个月。这些是训练经验的上下界，不是要求所有人每阶段都持续这么久。应结合比赛日期与实际反应决定。

> Scientific Principles of Strength Training, pp. 278–291 (printed page labels; PDF page index is label minus 1).

## 要点回顾

- 顺序有效的前提是先前适应得到保留。
- 阶段细节应服从更基础的原则。
