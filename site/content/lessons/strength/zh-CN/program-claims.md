# 没有魔法计划

计划名称不会引发适应。

## 既不靠口号，也不陷入停滞 {#program-claims-1}

“只管举”可能掩盖原则缺失；无止境关注小细节，也可能掩盖同样问题。来源提倡有依据地计划，持续执行，再批判性复查。比起脚尖微小角度或辅助动作顺序，更应先确认规定幅度、足够刺激和可恢复工作量是否存在。

逐日随机训练，会让进阶和反应难以解释。自我调节则不同：它为明确原因修改计划，同时保留目标。记录改变，让结果能指导下一次决策。努力与思考相互补充。

> Scientific Principles of Strength Training, pp. 353–355, 368–371 (printed page labels; PDF page index is label minus 1).

## 评价实际安排 {#program-claims-2}

本书最后同时拒绝“计划完全不重要”和“响亮名称能自动带来效果”两种信念。初学者可以在许多不完美计划下进步，高级者则常需要更精确匹配。很多结构在剂量、动作或进阶稍作调整后能有用，但任何名称都不能绕过原则。

面对新主张，应问：提出什么适应？相关比较是什么？涉及什么剂量与人群？测量了哪些成本？还有什么不确定性？课程传授来源推理，同时区分训练意见与测量事实。延伸阅读应回到原始情境，不应把书目列表当成自动成立的结论清单。

> Scientific Principles of Strength Training, pp. 353–355, 368–371 (printed page labels; PDF page index is label minus 1).

## 主张评价图 {#claim-decision-map}

| 主张 | 缺少的问题 |
|---|---|
| 著名运动员使用此工具 | 同时存在什么筛选、其他训练与恢复因素？ |
| 更多心肺让恢复感觉更好 | 目标力量结果也提高了吗？ |
| 活动能力总是越多越好 | 现在哪个必要姿势达不到或控制不了？ |
| 更低级别总是更有竞争力 | 力量、健康和相关评分情境如何改变？ |
| 更大体重等于更多有用能力 | 肌肉占多少，杠杆与舒适度怎样变化？ |
| 所有困难计划都等价 | 专项性、剂量、进阶与恢复是否真的一致？ |

本章十二主题可组织为：工具（弹力带铁链及器械）、剂量潮流（极高频与心肺）、推理错误（过度简化与细节执念）、任务适配（活动能力与冲突目标）、体重权衡（无必要降级与过度增重），以及计划主张（随机课与魔法方案）。每项都应使用同一框架检查，而不是换成相反口号。

**批判练习：** “这个工具带来了个人纪录，所以每个人都应该用。”纪录可能真实，但推断改变了人群、目标与比较。还应问负荷、练习、减量或既往适应是否也改变；解释阻力曲线为何可能迁移。合理机制支持试验，不证明普遍优越。反过来，某工具对力量举有限，也不代表对所有其他运动或娱乐目标都无用。

> Scientific Principles of Strength Training, pp. 344–371 (printed page labels and 1-based PDF pages coincide; 0-based PDF index is label minus 1).

## 要点回顾

- 计划名称不会引发适应。
- 用原则、实际结果与明确不确定性评价主张。
