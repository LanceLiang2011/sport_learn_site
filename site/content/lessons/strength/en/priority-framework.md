# A framework for decisions

Solve foundational programming problems before refining details.

## The seven principles {#priority-framework-1}

The authors rank the principles: **specificity → overload → fatigue management → stimulus–recovery–adaptation → variation → phase potentiation → individual difference**. Their ranking is a coaching framework, not a measured percentage contribution of each principle. Specificity establishes which adaptations matter. Overload supplies a meaningful stimulus. Fatigue management allows repeated productive work. The remaining principles refine when, how and for whom that work is arranged.

A program can follow the same principles with different exercises, frequencies or progression rules. The book explicitly presents a way to reason about programming rather than a proprietary routine.

## Audit in order {#priority-framework-2}

Consider a fictional bench program. It includes elaborate weekly exercise rotation but no substantial pressing and no progression. Improving the rotation cannot compensate for the absent relevant stimulus. First ask whether the plan trains the muscles and skill needed for the goal; next whether the stimulus is sufficient and progresses; then whether the workload can be recovered from.

Only after those checks should frequency, variation and phase details dominate the discussion. This order prevents an attractive small adjustment from hiding a large problem. Principles also constrain one another: more overload is not automatically better when it destroys recovery, and maximal specificity all year can prevent useful development of muscle and general strength.

> Scientific Principles of Strength Training, pp. 8–11, 21–25 (printed page labels; PDF page index is label minus 1).

## Why the order matters {#principle-decision-map}

| Priority | Its question | What the next principle cannot repair |
|---|---|---|
| Specificity | Are we training the needed systems? | More running cannot become specific squat training merely by progressing |
| Overload | Is there a meaningful, progressive stimulus? | Rest cannot create an absent stimulus |
| Fatigue management | Can hard work continue productively? | An ideal frequency cannot rescue indefinitely excessive demands |
| SRA | Are exposures sized and spaced usefully? | Exercise novelty does not fix every scheduling problem |
| Variation | Is the stimulus still productive and appropriately targeted? | Phase labels do not guarantee a relevant variant |
| Phase potentiation | Does earlier work support later work? | Personalization cannot reverse a missed preparation phase |
| Individual difference | How should quantities and details fit this lifter? | Calling a plan personal does not exempt it from the other principles |

The first three form the authors’ core workable framework. Specificity gives direction; overload creates the adaptation opportunity; fatigue management makes the process repeatable. SRA ranks lower because a range of sensible schedules can work once those basics are present. Variation can improve a plan already producing progress, but every useful change must still be specific and sufficiently demanding. Phase potentiation can improve long-term organization without being necessary for every beginner’s short-term gain. Individual differences matter, yet most adjustments modify shared mechanisms rather than replace them.

**Application:** if a fictional athlete rotates exercises expertly but performs too little relevant work, start by examining that dose. If the dose is relevant and substantial but performance collapses repeatedly, review recoverability. If those are satisfactory, investigate session distribution and longer-term staleness. This is an ordered investigation; it does not claim a single cause for every plateau.
