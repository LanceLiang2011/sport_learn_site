{id,title,subtitle,language,authors:string[],source:{title,authors:string[],edition:string,format,attribution},description,chapters:[{id,title,objectives:string[],lessons:[{id,title,summary,sections:[{id,title,markdown,source:string}],recap:string[],interactionIds:string[]}],quiz:[{id,objective,prompt,multiple:boolean,options:[{id,text,explanation}],correct:string[],explanation,source,lessonId}]}],glossary:[{id,term,aliases:string[],definition,source,lessonIds:string[]}],interactions:[{id,type:'volume'|'intensity'|'recovery'|'sequence',title,lessonId,source,objective,rationale,assumptions,staticAlternative,verification,config:object}]}
Markdown prose: paragraphs, lists, tables; explicit term links use [term](term:term-id). All IDs URL-safe lowercase hyphenated, unique within course for lessons/sections/questions/terms/interactions. Source locators plain truthful text, never private file links. Prose is original and complete in English and Simplified Chinese, with identical stable IDs and source citations. Markdown companion files live in content/lessons/{id}/{locale}/{lesson}.md and are generated from section markdown by scripts/validate-content.ts --write-markdown. Include real authored content, at least 5 chapter quiz questions. Interactions supported generic types: volume (sets x reps x kg), intensity (load / 1RM x100), recovery (qualitative scenario decision; config.scenarios [{id,label,feedback}]), sequence (step explorer; config.steps [{title,description}]). Set config appropriate for these only; source-backed educational assumptions; no invented physiological model. Private ledger belongs ../../private/{course-id}/, never content.
